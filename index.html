그리는 방법과 저장되는 정보
  • 가로선 → 세로선 → 원 → X → 하트 순서입니다. 오른쪽 목록에서 문양을 직접 고를 수도 있습니다.
  • X는 대각선 하나를 그린 뒤 버튼을 떼고, 반대 대각선을 그립니다. 두 획을 모두 그린 뒤 기록하세요.
  • 그림을 따라 그리는 배경 도안은 없습니다. 평소처럼 그리고, 찌그러진 그림도 남겨 주세요. 다른 문양을 그렸거나 실수로 등록했을 때만 다시 그리세요.
  • ‘이전 그림 다시 그리기’를 여러 번 누르면 이전 제출을 하나씩 볼 수 있습니다. 위에 그려야 했던 문양, 아래에 실제 제출한 그림이 나옵니다. 틀린 그림은 ‘이 그림 다시 그리기’ → 새로 그리기 → ‘수정한 그림 저장’으로 바꾸세요. 다른 기록과 수집 중이던 그림은 그대로 남습니다. 확인을 마치면 ‘수집하던 곳으로 돌아가기’를 누르세요.
  • 수정을 시작한 뒤에는 저장하거나 ‘수정 취소’로 원래 그림으로 돌아간 후 이동하세요. 이미 받은 JSON 파일은 바뀌지 않으므로 수정을 마친 뒤 새로 내려받은 최종 파일만 보내 주세요.
  • 좌표, 획 구분, 입력 시간, 그리기 영역 크기, 작성자 번호와 정답 문양을 저장합니다. 이미지나 인식 점수는 저장하지 않습니다.
  • 브라우저 자동 보관은 파일 백업과 다릅니다. 브라우저 기록을 지우거나 HTML을 옮기기 전에 JSON을 저장하세요. 진행 중인 그림도 JSON에 포함됩니다.
  • JSON을 불러오면 별도의 보관본으로 이어합니다. 기존 수집은 지우지 않습니다. 완료 후 JSON 파일을 카톡으로 전달하세요. 공유 링크를 카톡에서 받았다면 PC Chrome·Edge 또는 Safari에서 여세요.
